# Проверка

`python3 -m venv .venv && .venv/bin/python -m pip install pytest`, затем `.venv/bin/python -m pytest -q`. Тесты используют временные базы и имитацию окон; реальная сессия не меняется. Проверены ротация, ручные снимки, дедупликация, повреждение строки, версия схемы, повторный запуск, одинаковые классы, прерванный запуск, таймаут, dry-run, масштабирование монитора, отказ, исключения, отсутствие Hyprland и фильтрация адреса. Работа со снимками живой сессии проверяется отдельным smoke-тестом с временными XDG-каталогами. GTK GUI запускался на две секунды с временной базой; нажатия и реальное перемещение окон не проверялись. Специальные тесты tmux/SSH/отсутствующего каталога не реализованы, поскольку эти функции не реализованы.

Проверены закрепление и ротация, создание целостной резервной копии, настройка лимита и безопасный запуск Kitty с доверенным cwd; определение одной shell-сессии проверяется на локальном дочернем процессе. Действия GTK настройки и отмены удаления проверялись на временной базе.

Phoenix 1.1: `.venv/bin/python -m pytest -q` проверяет регистрацию адаптеров, безопасную сериализацию, дедупликацию архивов, квоты, порчу, миграцию 4→5, выбор панелей, прерывание и идемпотентность. Реальный интеграционный тест проводился с двумя временными Kitty OS-процессами и временными закрытыми сокетами: две вкладки / три панели были собраны и воссозданы, архивы прочитаны. Действия настроек, плана и просмотра архива проверялись в GTK на временной базе. Эти проверки не доказывают точность произвольных layouts и многооконных Kitty-сценариев.
