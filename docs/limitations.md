# Ограничения

Phoenix восстанавливает окна и расположение best-effort. Пользователь проверил восстановление своих окон в реальной сессии; это не гарантирует такого результата для любого приложения и конфигурации мониторов. Особые workspace, перенос workspace между мониторами и fullscreen state 3 пока не поддерживаются; tiled-расположение определяет Hyprland. Одинаковые окна могут сопоставиться неоднозначно.

Kitty может восстанавливать вкладки и панели с помощью явно настроенного приватного сокета при однозначном сопоставлении OS-окон независимых процессов. Несколько OS-окон одного процесса не сопоставляются по догадкам. Точное дерево и размеры splits, а также работающие программы не восстанавливаются. При неоднозначных уже открытых окнах Kitty восстановление не меняет эти окна. Без сокета доступен fallback для одной shell-сессии. Исторический текст терминала собирается только при отдельном opt-in; историю ввода Phoenix не собирает. SSH, tmux, процессы в памяти, каталоги файлового менеджера и проекты Codex специализированно не восстанавливаются. Состояние браузера зависит от его собственных настроек. Подробности: [Kitty](kitty.md).

Скриншоты доступны только для видимых столов. Для других может показываться более ранний кадр с отметкой времени или схема окон. Смена стола фиксируется после перехода; быстрые переходы объединяются. Блокировка сеанса, видимый Phoenix и исключённые приложения могут препятствовать захвату.

SQLite-бэкапы создаются локально, но автоматическое восстановление повреждённой базы пока не реализовано. Удаление снимка не гарантирует удаления отдельных кадров, которые используются другими снимками, и копий, уже попавших в резервную базу. Переключение настроек скриншотов не удаляет предыдущие изображения. Hyprland до 0.55 не поддерживается.
