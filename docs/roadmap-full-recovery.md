# Полное восстановление сессии: архитектура и дорожная карта

## Основа и границы

База — `main` 440707dc (схема SQLite 5) и сохранённые отдельно изменения экранных кадров. Действующий демон использует другой checkout; экспериментальная ветка не подключена к пользовательской базе. Снимок — неизменяемое историческое описание, а live-кадры в GUI лишь отдельно помеченный предпросмотр. Сбор адаптеров ограничен по времени, объёму и правам; произвольные команды, history и переменные окружения не исполняются и не сохраняются.

Поток: Collector → ограниченные Application Adapters → SnapshotManager (атомарный снимок и отдельные дедуплицированные архивы) → RecoveryPlanner → проверка адресных разрешений → RecoveryExecutor и устойчивый журнал → RecoveryVerifier → GTK/CLI. Наличие окна не доказывает восстановление состояния программы. Статусы интерфейса: exact только при проверке заявленного объёма; partial; unavailable; uncertain; skipped; failed. В текущем API `unsupported` соответствует unavailable; несовместимую замену публичного enum делать лишь вместе с миграцией потребителей.

## Матрица возможностей

| Компонент | Уже есть | Дальнейшая работа и граница доверия |
| --- | --- | --- |
| Kitty | Приватные сокеты, достоверное сопоставление нескольких OS-окон, вкладки/панели/cwd, опциональный архив | Native session может содержать команды; только разбор с белым списком и независимая проверка соответствия, без исполнения исходного файла. Точную геометрию не обещать до проверки. |
| Codex CLI | Нет привязки сеанса к панели | Сохранять только доказанный ID и проект; проверять локальную сессию, не использовать `--last` для конкретного разговора; запуск по политике, без содержимого диалога. |
| tmux | Отдельного адаптера нет | Выделенный сервер/сокет в тестах, имена и геометрия; без модификации существующих сеансов и конфигурации; tmux-resurrect только при наличии и разрешении. |
| SSH/процессы | Нет восстановления | SSH и сетевые действия только после адресного подтверждения; неизвестные команды по умолчанию запрещены. |
| Hyprland | Частичное размещение и дедупликация, журнал запуска | Мониторы, focus и проверка результата; неоднозначность не устранять угадыванием. |
| Opera/VS Code | Общий запуск desktop-файла | Штатное восстановление самих приложений; не создавать вручную копии вкладок/окон. Hot Exit не гарантирует состояние после всех аварий. |
| Архивы | Опциональный scrollback, квота, дедупликация, безопасный viewer | Поиск, честное обозначение усечения и связь с восстановленной панелью при проверяемой идентичности. |

## Данные и разрешения

Версионированные данные каждого адаптера включают источник, время сбора, полноту и ограничения; нестабильные PID и адреса пригодны только для идентификации в текущем сеансе. Перед дальнейшей миграцией SQLite необходимы integrity_check, SQLite Backup API, отдельный неперезаписываемый backup и транзакция. Исторические данные и архивы остаются совместимыми. Рабочие каталоги могут быть чувствительными. Архивы и native exports — opt-in; export может содержать секреты даже без foreground-флага. Raw export не хранится и не исполняется по умолчанию.

Открытие окна, cwd и реконструкция безопасных панелей разрешены выбранным пользователем режимом. Подтверждённый конкретный Codex ID — только в соответствии с политикой; сеть/SSH и программы с побочными эффектами — отдельное подтверждение. Неизвестные и произвольные shell-команды запрещены. Подтверждение не передаётся другим объектам или последующим запускам.

## Этапы

0. Аудит, контракты, базовые тесты и журнал прогресса.
1. Kitty: исследование документированного экспорта, безопасный ограниченный разбор, качественная проверка геометрии в отдельных экземплярах, архивный viewer.
2. Codex: достоверная идентификация, проверка и разрешённый resume.
3. tmux: изоляция, сбор, проверяемое восстановление без перезаписи живых сессий.
4. SSH и разрешённые программы: явные адресные разрешения.
5. Hyprland: мониторы, рабочие столы и проверка фактических окон.
6. Адаптеры приложений: документированные штатные механизмы.
7. История, выборочное восстановление и понятный отчёт в GUI.
8. Изолированные сквозные, аварийные и нагрузочные проверки и релиз-кандидат.

## Источники и технические выводы

- [Kitty sessions и save_as_session](https://sw.kovidgoyal.net/kitty/sessions/): action доступен и через `kitten @ action`; `--save-only` не открывает редактор, `--use-foreground-process` может повторно исполнить опасную команду и требует shell integration. `--relocatable` меняет смысл путей, поэтому автоматом не включать.
- [Kitty remote control](https://sw.kovidgoyal.net/kitty/remote-control/) и `kitten @ action --help` установленного Kitty 0.49.2: действие требует доступа к сокету; оно выполняется внутри целевого процесса. Версию и доступность необходимо проверять в изолированном экземпляре, а не только по документации.
- [Справка Codex CLI](https://learn.chatgpt.com/docs/developer-commands?surface=cli): установленный `codex-cli 0.164.0`, `codex resume --help` принимает конкретный UUID; `--last` не обеспечивает идентичность нужного разговора.
- [tmux-resurrect](https://github.com/tmux-plugins/tmux-resurrect): сторонний плагин, не устанавливать и не подключать без разрешения.
- [VS Code Hot Exit](https://code.visualstudio.com/docs/editing/codebasics#_hot-exit): поведение и параметры принадлежат приложению; не выдавать его штатное восстановление за проверенное восстановление Phoenix.
- [Hyprland IPC](https://wiki.hypr.land/IPC/): наблюдение после переключения не позволяет получить кадр покинутого стола точно перед нажатием; IPC не делает непроверенное сопоставление окон надёжным.

## Проверки

Unit и регрессии всегда используют временные базы. Живые проверки — только отдельные Kitty, временные XDG-каталоги, сокеты и процессы теста. Никаких реальных перезагрузок, остановки пользовательского daemon или изменений `kitty.conf`. Дополнительно: прерывание сохранения и восстановления, дубликаты, неоднозначность, повреждение, отсутствие программ, конфликты, приватность, производительность и совместимость. Для каждого этапа фиксировать реально выполненные проверки, не extrapolate microbenchmarks.
