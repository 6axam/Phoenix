## Следующие конкретные шаги

1. Изолированно исследовать `kitten @ action save_as_session --save-only`, отличия `ls` и экспортированных layout state, явные границы документации и безопасность импорта.
2. Реализовать только проверяемые улучшения Kitty и viewer; тестировать отдельно и фиксировать известные ограничения.
3. Не считать Codex/tmux/SSH восстановленными до реальной реализации и отдельных проверок. Не включать эти функции без адресных разрешений.
4. Следующие шаги отслеживать отдельными коммитами. Не менять работающий daemon, пользовательскую базу, терминалы и kitty.conf; не сливать main.

## Milestone 1 — начат, частично реализован

- `phoenix/adapters/kitty.py`: приблизительная категория foreground-процесса из Kitty metadata (только фиксированный whitelist, никаких argv, env или адресов); категории не разрешают запуск. Повреждённые категории отклоняются. `phoenix/gui.py`: категория видна в деталях панели; архивный viewer показывает время снимка, статус усечения и поиск по первым 256 КиБ. `tests/test_kitty.py`: проверки секретов, неоднозначности и повреждения; `tests/test_kitty_integration.py`: реальный native export без исполнения в отдельном Kitty.
- Изолированный тест в Hyprland: `kitten @ action save_as_session --save-only` создал экспорт с тремя split-панелями; исходный файл не исполнялся. Raw export может содержать команды: штатное восстановление из него не реализовано. На данный момент точность смешанного split остаётся частичной, и запуск Codex/tmux/SSH не реализован.
- Полный прогон с `PHOENIX_KITTY_INTEGRATION=1`: 97 passed за 13.79 с, включая все доступные изолированные живые проверки Kitty. Тесты запускают и завершают лишь собственные Kitty, используют отдельные XDG и SQLite; производительность в этом этапе не измерялась.
- Схема SQLite не изменялась. Действующий daemon и пользовательские данные не модифицированы. Для включения новых функций потребуется отдельный согласованный переход и проверка; откат экспериментального checkout — просто вернуться к прежней версии без миграции данных.
- Далее: безопасное выделение геометрии native export (внутренние сериализованные ID/команды требуют строгой валидации и проверки версий), точная идентификация сессий Codex, tmux и SSH, изолированный E2E. Не считать milestone завершённым.
